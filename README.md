# workbuddy-expert-studio

**WorkBuddy 专家开发工坊** · v1.0.2 · `team`

> Turn an expert idea into a publishable package, step by step


Part of the [Lucewalk Lumen](https://github.com/Lucewalk-Lumen/about-me) collection.


## What it does

- **Alignment first** — the lead restates what to build, for whom and to what standard before any work starts
- **Six specialists** — architect (design), engineer (build), diagnostician (troubleshoot), auditor (quality gates), packager (release), release-chronicler (history)
- **Step-gated delivery** — design → build → quality check → packaging, each step with explicit acceptance criteria
- **Pre-delivery health check** — completeness, length, citation and path safety are verified automatically

## How it works

- This studio produced every product in the [Lucewalk Lumen](https://github.com/Lucewalk-Lumen/about-me) catalog
- Two dedicated skills: the studio toolkit and a web crawler for material gathering
- Not-datum-not-advance: quality gates block the next step until the current one passes

## How to use / 如何使用

This is an **expert package / skill for the WorkBuddy AI assistant**.

**Prerequisites · 前置条件**
- WorkBuddy installed and signed in (latest version recommended).
- Prepare your own materials first (e.g. your literature library / course outline) — the agent works under a "stay faithful to the source, cite the page" rule.

**Import / enable · 导入 / 启用**
1. Download the package zip from this repo's **Releases**, or clone the repo; keep the `.codebuddy-plugin/` manifest intact.
2. In WorkBuddy, *custom connector → trust & enable*, or import the expert / enable the skill from the skill center.
3. Run one minimal example below to confirm the output matches your standards.

**Minimal example · 最小示例**
> 把一个专家想法走完 对齐 → 起草 → 质量门 → 打包 全流程。


**Portability · 可移植性** — Delivered for WorkBuddy; won't run as-is elsewhere, but the methodology is documented in plain text and can be re-implemented on another platform. Knowledge is portable even if the runtime isn't.
